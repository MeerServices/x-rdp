# X-RDP

Hulppagina's voor X-RDP (overzicht van X-Cubes via Chrome Remote Desktop):

- `go.html` – stuurt een Remote Desktop-, Google- of UniFi-link door naar de gekozen browser (Android) of het gekozen Chrome-profiel (pc, via X-RDP.exe). Slaat niets op.
- `X-RDP.zip` – Windows-hulpprogramma X-RDP.exe.
- `index.html` – startpagina met links.
